# v0.6 右键与拖拽体验

这是应用内体验版。用户认可 v0.5 后提出右键、拖拽；本次先体验动作，确认后再开放用于真实桌面的数日试用版本。

## 启动

退出旧窗口，Mac 双击 `launch_tripod_mac.command`，Windows 双击 `launch_tripod_windows.cmd`。点击「启动摄像头」，进入「点击与拖拽实验」。先保持原来的 30% 移动范围与标准抗抖。

| 操作 | 动作 | 画面反馈 |
|---|---|---|
| 定位 | 拇中捏住、食指移开，小幅移动 | 光标跟随拇中点 |
| 左键 | 食拇短捏，再松开食指 | 接触时按下变色，松开完成单击 |
| 右键 | 食指移开，拇指＋无名指轻捏 | 指针先冻结，显示右键已触发；保持不重复 |
| 拖拽 | 食拇捏住，进度环满后移动，松食指放下 | 默认按下后等 0.30 秒，拖拽就绪提示 |
| 换手位 | 松中指锁定，挪到舒服位置，再捏中指 | 从原光标位置继续；拖拽时食拇可一直捏住 |
| 暂停 | Esc 或「暂停手势」 | 结束按住，恢复后须重新接管 |

左键与 v0.5 的区别：完整点击现在在松开时完成，便于同一操作兼容按住拖拽；没有先单击再二次按下的额外事件。

## 建议先试三轮

1. **点击目标**：轻点 8 个目标，确认松开的时机自然；其中几次松中指锁住后再点。
2. **右键目标**：无名指先离开拇指一下，再捏合。食指保持分开；紫色目标只接受右键，左键会记录为失误。可以松中指后再右击。
3. **拖拽到圆环**：移到橙色方块上，食拇捏住，等进度环满，再拖到圆环中松食指。途中试一次松中指换位，以及 Esc/手移出画面取消。

先关注无名指是否别扭、左键松开是否拖沓、0.30 秒拖拽等待是否合适、放下物体时是否偏移。一次只调整一个档位。保持多久舒服由使用者决定，不把持续操作时间当成达标要求。

每轮结果在 `reports/tasks/`，含版本、任务、按钮、配置与完成/取消信息；离散事件在 `data/events/`，不保存视频。练习圈内的合成验证不是人的准确率。Windows 仍需要实际设备试用。

## 进入数日桌面试用前

本轮源代码和安装包已具备右键事件适配，但实验模式仍禁止系统输出。收到实际动作体验反馈后，先据反馈调整，再为该模式开放显式启用系统控制、确认双平台按键释放与前后台退出，并提供单独试用入口。后续记录误触、掉手、拖拽放下、舒适度和版本，不自动上传数据。本轮不把合成成功或一次主观认可写成稳定产品结论。
