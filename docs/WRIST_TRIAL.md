# v0.10.1 手腕转动试用

本轮目标：前臂放在桌面或扶手上，主要靠小幅转腕定位；转动结束后光标停止，不需要持续抬胳膊平移。模式基于估计的掌部朝向，仍需相机能看清掌部和指尖。实现与合成验证完成不代表真人手感已经达标。

## 开始

1. 先按 Esc 停止旧版、退出窗口。Mac 用 `launch_desktop_mac.command`，Windows 源码用 `launch_desktop_windows.cmd`，确认标题版本为 **0.10.1**。旧0.8.1便携ZIP保持留档，不包含本轮功能。
2. 支撑前臂，调整屏幕/相机角度，让舒服的手位处于画面内；先只露出控制手。点「启动相机」。
3. 展开手感设置，将「定位方式」改为「手腕转动 · 实验」。第一次未校准时不能启用鼠标。
4. 点「三步腕动方向校准」。程序关闭系统输入，按当前步骤的循环姿势动画做参考：**自然握持 → 轻向右转腕并停住 → 回中立后轻向上转腕并停住**。前臂保持支撑、手指自然放松并保持相近手形；不用照抄动画手形，也不要求捏合。不要只弯手指来示范转腕。
5. 每步有效姿态收集足够且稳定后自动通过；没准备好就继续等待，不赶时间。第三步会先提示回中立，再提示向上。三步成功后手回自然位置，再点「启用鼠标控制」，食指移开、拇中轻捏接管。

右侧会显示有效姿态帧数、估计偏转、参考范围及不足原因；失败或取消原因会留在校准区域。每步最近36帧中需有30个有效掌姿，最新30个有效姿态稳定；低帧率可以多等一会儿，时间本身不会决定通过。坏姿态和晃动会被后续新数据替换，之前通过的步骤保留。

示范只定义方向，不决定灵敏度。建议示范约10–20度的舒适转动；过小、过大、两个方向太相似、采样不连续或波动大时停在当前步骤提示调整。校准不保存图像或关键点序列；保存15个方向参数，开启本地记录时还保存各步计数、角度统计和拒绝原因。改变机位、控制手或握持姿势后重做校准。实验模式需要腕点和掌指关节可用，不能依赖手出画面后继续追踪。动画只是动作示意，不代表相机已识别成功；实际通过依据是旁边的采集数据。

## 使用

- **移动：** 拇中保持轻捏，转腕。1.00×灵敏度下，理想估计角度45度对应一屏；实际所需幅度受模型估计影响。仍可用0.10×～2.00×滑条调整。
- **回位：** 松中指锁住光标，把手腕放回舒适姿势，再捏住中指继续。回位期间不必搬动胳膊。
- **左键和拖拽：** 食拇短捏后松开完成左键；保持约0.30秒进入拖拽。拖拽时可保持食拇捏合，只松中指回位，重新捏中指继续拖；松食指放下。
- **右键：** 食指移开，拇指与无名指轻捏。
- **滚动：** 仍用V手势和小幅上下移动，收指停止；本轮没有把滚动改成腕动。
- **停止：** Esc；相机缺手、跟踪跳变或姿态不可用也会停止当前手势、释放按键。

腕动采用固定增益的精细滤波，不会因为转得快而额外加速；手停后会有短暂滤波收敛，不能承诺零延迟。位置模式的原版/精细/自适应选择和静止噪声校准都保留，切回后继续使用。腕动不套用原位置噪声校准，当前「6秒静止校准」在此模式不可用，抗抖强度仍可调整。

超过校准中立约65度、单帧突变超过约25度，或者掌部投影过于侧斜时，本实验会暂停并松键，提示调整姿势。这些阈值是保护实验范围的工程参数，不是相机精度或人体转角测量结果。

## 先比较这几项

用同一机位、同一前臂支撑姿势，交替选择「指尖位置」与「手腕转动」：

| 体验 | 观察什么 |
|---|---|
| 静止5秒、向左右/上下各轻转一次 | 是否保持方向、停下后是否漂移；转动是否误断 |
| 小按钮附近反向微调 | 是否不必挪胳膊；小动作是否被抗抖吞掉 |
| 同位置单击/双击 | 点击时光标是否被牵动 |
| 拖一段、松中指回位、继续拖 | 是否保持拖拽、回位接管是否跳动 |
| 手稍转斜后回正 | 是否经常提示掌部不可用；是否比位置模式更顺畅 |

先在普通练习窗口短试。若向右/向上方向不符合示范，先重做校准；若只是太快，用灵敏度滑条。若经常姿态不可用，调整机位或切回原来的指尖位置模式；原版手感没有被腕动模式替换。

本轮没有训练新ML模型。它把姿态映射与点击手势分开，并修正新模式的3D捏合距离/2D掌尺度混用；仍无法修复底层模型遮挡和深度估计错误。真人准确度、停止延迟、疲劳改善及Windows原生输入均需实测，见 [验证记录](VALIDATION.md)。
