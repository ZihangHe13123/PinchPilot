## v0.10.0 腕动位移实验

按用户选择实现“转多少移动多少，停腕即停”的独立定位方式。使用掌部朝向、三姿态方向示范、固定角度增益和精细滤波；每次拇中接管重锚。示范只学习方向，灵敏度不因示范幅度变小而放大。新模式的捏合距离和掌尺度同用估计3D坐标；原位置算法及参数保持。操作和限制见 [WRIST_TRIAL.md](WRIST_TRIAL.md)。

- 完整测试 **438项通过，5.00秒**，包括既有位置/手势/平台接口回归和新增腕动几何、校准、控制生命周期及UI测试。JUnit：`reports/verification/wrist-0.10.0/pytest.xml`；Ruff检查和60个文件格式检查通过。
- 核心新增34项合成测试：平移/尺度/图像宽高比不变性，旋转下捏合尺度一致，示范幅度不改变增益，快慢旋转终点与静止保持，方向/反向微调，指尖动作不驱动定位，噪声抑制与小修正，拖拽换位，靠屏幕边缘反向，左右键和V滚动。缺手/姿态跳变/超范围/投影退化/换手/超时均验证松键一次，并且保持点击姿态返回不会自动重按。
- 校准覆盖坏参数、示范过小/过大/方向过近、姿态波动、缺失、换手等拒绝。独立只读审查额外验证SO(3)近零/近π/π的45组往返，最大误差约7.57e-10 rad；这是数值算法检查，不是相机角度精度。
- FakeMouse验证未校准禁止创建输入、采集前释放、取消/超时/切换来源/模式/关闭均停止，旧校准不被失败结果覆盖，成功不自动启用，位置噪声不混入腕动。
- Qt离屏用真实 `WristCalibration` 处理366帧合成三姿态，经consume→tick→config→UI保存15参数，最终100%，启用按钮可用但未勾选，未创建任何原生输入对象。已查看未校准、采集中、成功三张截图；采集按钮、进度及阶段提示在可滚动区域内可见。截图与逐项几何结果在同目录 `ui-wrist-summary.json`；其来源明确标记为合成离屏。
- 重新执行位置移动对照：原版/精细/自适应各六种输入，以及独立静止校准结果，与v0.9.1逐项一致。仅比较时忽略新增的两个默认配置字段，未改写旧报告。结果在 `position-regression.json` 与 `position-motion/`。
- 源码包和wheel构建成功，核对新模块/试用文档存在且不包含个人数据、报告或虚拟环境。把wheel安装到独立临时目录，复用本机依赖，验证实际导入v0.10.0及腕动模块，再运行2秒离屏合成桌面并正常退出。构建校验值见同目录 `package-checks.json`。既有便携ZIP没有重建或覆盖。

本轮没有打开相机、操作真实系统鼠标或修改用户现有偏好。实际MediaPipe深度稳定性、侧斜姿态的退出频率、操作疲劳、停止余动和Windows原生运行仍待真人验证。腕动校准暂不包含噪声学习，不承诺替代所有日常鼠标使用；不将理想刚体旋转测试当作真人识别率。

## v0.9.0 非 ML 移动调优

已加入原版、精细、自适应三种移动方式，保持现有手势；全新桌面配置默认精细，已有旧版设置缺少模式字段时迁移为原版，保存的新模式照常恢复。静止校准准备1秒、采集5秒，先关闭输入并释放按键，结束、取消或失败均不自动恢复。校准样本不落盘，只保存参数及估计摘要；UI 的采集时波动不冒充实时数据。

## v0.8.2 双击与控制手修复

用户随后将项目目标调整为“用尽可能少和小的动作稳定操控”，并追加单指交互候选。最初目标更新仅同步研究计划、计量定义和试采协议；随后授权的两个单指 demo 已在 v0.3 实施，证据见上节。动作计量、速度相关指针增益、连续标注与时序 CNN 仍待实施；上述 58 项测试属于 v0.2 历史工程证据。

## 自动检查覆盖

- 单次捏合只按下一次，单帧噪声不点击，规则闭合/释放阈值滞回。
- 丢手、相机时间间隔过长、暂停、重置、非法时间戳、换手、握拳/other、持续低置信度输入结束按下；重新捏合不能跳过张开启用。
- 稳定拖拽起点不跳动、光标边界限制、滚动与点击互斥。
- 特征在平移/统一缩放及宽高比等价转换下保持一致；退化、缺失或 NaN 几何拒绝。
- 人工标签、递增时间戳、重复 episode 拒绝、校准样本条件。
- 参与者划分不重叠；RF/SVM 训练、保存、加载、运行时拒识与评测一致；混淆矩阵不遗漏拒识及额外预测类。
- Win32 INPUT 字节布局、负滚轮编码、模拟输入拒绝、按下后关闭释放；macOS 模拟权限拒绝及拖拽/释放。
- 演示不能录成训练数据或构造真实鼠标输出；后台结果回到 GUI 线程；停止后下载/授权不能重新打开相机；模拟任务可完成并标明合成来源。
- 模型下载/缓存校验；停止的相机线程不打开硬件；Windows 模拟 DirectShow→MSMF 回退和资源释放。

## 待真人/硬件验收

按顺序在 Mac 和 Windows 各完成一次，记录 OS、芯片、相机、显示器/DPI 和依赖版本。

- [ ] 用户通过系统相机授权，启动预览，看到真实关键点与镜像方向一致。
- [ ] 指尖可见/轻微遮挡、左手/右手、两个距离和两种光线下检查掉手与错误判定。
- [ ] 应用内完成 8 目标点击与拖拽，检查日志和画面一致。

- [ ] 应用失去前台焦点时按 Esc，确认退出系统控制；测试按住实体鼠标的干预方式。
- [ ] Windows 100%/150%/200% 缩放、内置/USB 相机；单主屏范围与光标一致。
- [ ] Mac Retina/缩放显示模式与相机释放后再次启动。
