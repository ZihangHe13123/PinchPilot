## 自动检查覆盖

- 单次捏合只按下一次，单帧噪声不点击，规则闭合/释放阈值滞回。
- 丢手、相机时间间隔过长、暂停、重置、非法时间戳、换手、握拳/other、持续低置信度输入结束按下；重新捏合不能跳过张开启用。
- 稳定拖拽起点不跳动、光标边界限制、滚动与点击互斥。
- 特征在平移/统一缩放及宽高比等价转换下保持一致；退化、缺失或 NaN 几何拒绝。
- 人工标签、递增时间戳、重复 episode 拒绝、校准样本条件。
- 参与者划分不重叠；RF/SVM 训练、保存、加载、运行时拒识与评测一致；混淆矩阵不遗漏拒识及额外预测类。
- Win32 INPUT 字节布局、负滚轮编码、模拟输入拒绝、按下后关闭释放；macOS 模拟权限拒绝及拖拽/释放。
- 演示不能录成训练数据或构造真实鼠标输出；后台结果回到 GUI 线程；停止后下载/授权不能重新打开相机；模拟任务可完成并标明合成来源。
- 模型下载/缓存校验；停止的相机线程不打开硬件；Windows 模拟 DirectShow→MSMF 回退和资源释放。

## 待真人/硬件验收

按顺序在 Mac 和 Windows 各完成一次，记录 OS、芯片、相机、显示器/DPI 和依赖版本。

- [ ] 用户通过系统相机授权，启动预览，看到真实关键点与镜像方向一致。
- [ ] 指尖可见/轻微遮挡、左手/右手、两个距离和两种光线下检查掉手与错误判定。
- [ ] 应用内完成 8 目标点击与拖拽，检查日志和画面一致。

- [ ] 按下时手移出画面/遮挡/停止/切模型/关窗口，确认系统左键释放。
- [ ] 应用失去前台焦点时按 Esc，确认退出系统控制；测试按住实体鼠标的干预方式。
- [ ] Windows 100%/150%/200% 缩放、内置/USB 相机；单主屏范围与光标一致。
- [ ] Mac Retina/缩放显示模式与相机释放后再次启动。
