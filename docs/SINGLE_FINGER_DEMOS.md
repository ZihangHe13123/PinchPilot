# 两种单指 Demo：先试主动点击，再比较停留

**2026-09-21 更新：本方向暂搁置。** 用户反馈尽量只动食指仍严重晃动，交互难用。下面保留 v0.3 的历史操作与实现说明；现在优先试 [v0.4 三指方案](TRIPOD_DEMO.md)，不将单指的工程测试成功视为真人可用。

v0.3.0 已提供这两个可运行模式。它们与默认捏合共用摄像头和练习区；使用独立的单指规则，没有训练新的 CNN。MediaPipe 仍提供预训练关键点。当前只比较定位、左击与暂停，单指不接系统鼠标、拖拽或滚动。

## 怎么启动

退出已运行的旧窗口，再从项目目录启动：

| 平台 | 主动轻弯 | 停留点击 |
|---|---|---|
| Mac | 双击 `launch_flex_mac.command` | 双击 `launch_dwell_mac.command` |
| Windows | 双击 `launch_flex_windows.cmd` | 双击 `launch_dwell_windows.cmd` |
| 命令行 | `uv run pinchpilot gui --interaction finger-flex` | `uv run pinchpilot gui --interaction finger-dwell` |

入口不自动打开摄像头。可先点击「无相机演示」看动作与状态变化；这是合成关键点，不能当识别效果或人的任务成绩。点击「启动摄像头」后才是自己的真实手部输入。两个模式也可以在右侧下拉框中切换，切换会结束本轮任务。

## 先找到舒服且能看见的手位

1. 前臂放在桌面或扶手上，掌部尽量稳定；让相机能看见手掌结构与食指各关节。其他手指自然放松，不必一直用力伸直。
2. 舒展食指，保持约 0.2 秒。程序把当前食指姿势作为本次参照，以原指针位置接管；开始任务时则以练习区中心接管。
3. 小幅摆动食指，先看移动方向与范围。移动灵敏度默认 2.5，觉得不够灵活可试 3.5，觉得难以停稳可试 1.5。这些数值是归一化映射增益，不是厘米或疲劳下降比例。
4. 手位不舒服时，深弯食指或把手移出画面休息，再调整到舒适位置并舒展食指继续。Esc 可明确暂停。右侧「重新定位」保留指针位置、结束当前任务，随后可开始新一轮。

如果前臂支撑后相机根本看不到手，应先调整相机/屏幕角度或外置相机位置。不要为了完成测试继续抬着手；减少手指位移无法补偿不合适的机位。单指是“只主动动食指”，不保证仅有孤立指尖入镜也能识别。

## A：轻弯食指，主动点击

进入「点击与拖拽实验」，选择「点击目标」「手势 · 应用内」，点「开始 8 个目标」。将指针移到圆圈内，短暂轻弯食指，再恢复定位姿势。弯曲确认后状态提示“已识别轻弯”，恢复确认后才计一次点击。不要一直保持弯曲。

识别到弯曲起始时指针冻结，恢复后从冻结位置继续。一次弯曲—恢复最多产生一次点击；单帧波动、超过约 1.5 秒未完成、过深弯曲、丢手或换手取消本次动作。没有悬而未决的左键按下。

先用「默认轻弯」。动作漏检时可试「较轻」，但同时观察向下定位是否更容易误触；容易误触则试「更明显的弯曲」。这不是桌面触碰或压力检测，关节变化过小、遮挡或定位时也弯曲都可能造成混淆。

## B：停住，等进度环完成

开始后先移动到目标；仅仅初始伸指静止不会点击。停稳后出现黄色进度环，默认 0.8 秒完成一次点击。移出当前稳定范围会重新计时；丢手、明显改变食指姿势或暂停会取消。

点击后停在原处不会重复点击，必须移出更大的重新准备范围。停留时间可选 0.4–2 秒；越短等待越少，但停下来查看目标时也更容易误点。屏幕边缘以裁剪前的输入检查，持续向边缘外移动不会因光标被卡住而自动点击。

停留解决的是不再额外做点击动作，不能从“停住”直接判断人在选取还是阅读。应单独记录不想点击却触发的情况。

## 一次短试用记录什么

用同一机位、窗口大小和参与者编号，A/B 各练习一轮，再各做两轮 8 目标点击；下一位参与者交换顺序。两种模式只比点击，不与捏合的整套拖拽/滚动任务直接合并成绩。

| 项目 | 记录方式 |
|---|---|
| 任务完成、命中与失误、耗时 | `reports/tasks/task_*.jsonl` 自动记录；未完成轮次也保留 |
| 模式和灵敏度、停留时间 | 任务元数据与 `data/events/events_*.jsonl` 自动记录 |
| 轻弯是否误认成移动 / 点击带偏 / 没点出来 | 人工记次数和当时手位；事件日志本身不能证明用户意图 |
| 停留误点、等待太久 | 人工记录；等待必须包含在总耗时里 |
| 前臂是否有支撑、手指是否清楚可见 | 人工记录机位与姿势，不能用无相机演示替代 |
| 费力度 0–10、哪个模式更愿意继续用 | 每轮结束后记录；不是肌肉负担客观测量 |

设置改变会结束一轮，避免一个成绩混合多个配置。参与者和场次仍可编辑；单指模式禁用捏合四分类采集，避免标签混用。连续标注、动作成本自动计量和自己的时序 CNN 尚未实现。

## 实现和验证边界

指针使用食指尖相对掌部的位置，并除以掌部尺度；屈曲量使用食指两个关节的几何角度代理，舒展接管时建立基准。它不消除手部旋转、透视和追踪噪声，也不属于人体关节角度的测量仪。[MediaPipe 官方坐标说明](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/python#handle_and_display_results) 说明图像坐标的归一化与深度尺度，本原型据此做宽高比修正。

`uv run python scripts/check_single_finger.py` 会运行两种模式的无相机工程检查，生成截图与八目标结果，位置为 `reports/verification/single-finger/`。生成帧快于真实时间，所得任务耗时不能当真人表现。自动测试与离屏绘制通过不等于小动作准确率、疲劳或 Windows 硬件已经验收；详见 [验证记录](VALIDATION.md)。
