# 项目定位与推进顺序

## 建议题目

**PinchPilot: Personalized Webcam-Based Pinch Interaction for Desktop Control**

普通 RGB 摄像头下，面向前臂有支撑、小幅手部动作的捏合交互系统。研究问题：个人校准、可学习的手形判定与稳定定位，能否在合理延迟下减少误触和点击偏移，并完成实际点击/拖拽任务？

这是可验证的研究问题，尚不是已证实的产品优势。任务定位为部分桌面交互的补充；是否能长时间替代鼠标、是否减轻不适，需要真实参与者实验。

## 与课程要求的对应

依据 `PRS-PatternRecognitionSystems-Practice-Module 7.0 - FT.pdf` 第 9–10 页，课程允许实用模式识别系统，示例中直接包含 hand gesture recognition。要求至少覆盖列出的四个方面中的三个。

| 课程方面 | 本项目如何体现 | 需要交付的证据 |
|---|---|---|
| Supervised / unsupervised learning scenarios | 人工标注 open、pinch、scroll、other | 数据定义、标注过程、划分方式 |
| Machine learning / Deep learning techniques | 自训练 RF/SVM；复用 MediaPipe 视觉模型 | 训练脚本、模型、独立测试、基线比较 |
| Intelligent sensing / sense making techniques | 相机采集、关键点、归一化、时间确认到可执行交互 | 实时演示、延迟与故障处理测量 |
| Hybrid ML / Ensemble approach | Random Forest 本身是树集成，可分析与 SVM 的差异 | 实际模型比较，不能仅把规则外壳称为集成学习 |

前三项形成明确对应。ML/DL 在原要求里是同一条，不能把二者拆成两条凑数。复用 MediaPipe 必须标明；自有贡献需要体现于数据、分类器、交互设计和实验，而不能只展示一个库调用。具体评分由教师判断。

第 15–16 页要求：可运行系统、数据集、最终报告、源代码/模型/支持材料、10–15 分钟视频、两次汇报的幻灯片；每人另交 1–2 页个人报告并完成 peer review。团队最终交一个 ZIP，个人报告除外。

## 与 Pawvis 的关系和可做的亮点

参考版本：Pawvis commit `039e6d8ede814cb943532b841e6c78f83fba1f62`。它的默认点击是食指下压；已有校准、点击稳位、拖拽处理、注意力门控和 DTW 自定义手势模板。不要写成「Pawvis 只有简单阈值，没有学习或个性化」。

本项目独立实现，采用 VR 风格的拇指/食指捏合选取，并以跨平台的真实交互评测作为交付重点。捏合本身已有广泛先例，也不是学术首创。适合课程的贡献是：

1. **把用户差异量化。** 同一批独立测试者，比较固定规则、自训练分类器以及单独场次的个人校准；知道哪些手形/角度失败。
2. **把点击位移量化。** 固定其他条件，比较稳定定位开启/关闭，记录误点、完成时间、拖拽成功率，并披露额外延迟。
3. **把舒适度目标落到任务。** 用前臂支撑、短程动作，和鼠标/触控板做相同任务；收集主观评分，接受结果可能不优于物理输入。
4. **同一核心覆盖两种桌面系统。** 记录不同相机、分辨率、DPI 和权限路径的验收结果。

「无意 vs 有意」的隐式意图模型、时序网络、三维缩放、复杂动态手势都留作扩展。先以明确的捏合和张开启用机制建立可靠基线，再判断是否值得增加模型复杂度。

## ML 难度与具体顺序

第一版 ML 难点主要在数据与评估，而非搭网络。21 点由预训练模型提供；本项目从中取 12 个几何特征，用 CPU 就能训练小分类器。更多帧不会自动等于更多独立样本。

| 顺序 | 工作 | 完成标准 | 当前状态 |
|---|---|---|---|
| 1 | 需求、规则交互、退出条件 | 明确单手/主屏/点击/拖拽/滚动 | 已实现 |
| 2 | 共用 GUI、模型推理、平台接口 | 能预览、回放、解释权限；真人操作另验 | 工程检查已跑，真机交互待验 |
| 3 | 少量试采与几何调参 | 三位组员每人完成一次完整手形采集 | 待真人参与 |
| 4 | 完整数据集与 RF/SVM | 参与者分组、混淆矩阵、拒识、失效例 | 工具已实现，研究数据待采 |
| 5 | 校准/稳定定位/输入设备对照 | 同任务、不同条件、保留原始日志 | 任务工具已实现，实验待做 |
| 6 | 根据失败实例迭代 | 用验证数据调参；独立测试保持未见 | 待试采后决定 |
| 7 | 双平台验收与正式交付 | 启动说明、模型、数据、报告、视频可复现 | 待硬件验收和正式材料 |

## 三人分工建议

- A：交互与系统。摄像头、状态机、Mac/Windows 适配、故障验收，组织真实 demo。
- B：数据与学习。采集质检、RF/SVM、划分与误差分析、可复现实验。
- C：用户任务与报告。招募/同意、任务顺序与设备记录、指标/图表、汇报材料。

三人都参与采集与代码理解；每人维护自己的贡献记录，个人反思依据实际工作撰写。

## Proposal 可用摘要（草稿）

本项目拟构建一套可在 macOS 和 Windows 使用的普通摄像头手势交互系统。系统通过预训练手部关键点模型获取手形信息，使用人工标注数据训练轻量分类器，将捏合、张开及滚动手形映射为桌面操作，并由确定性状态机管理点击与拖拽。项目将比较固定规则与机器学习判定、默认与个人校准参数、稳定定位开启与关闭的表现，并通过统一的点击/拖拽任务评估完成时间、误操作和主观舒适度。主要交付包括跨平台原型、匿名关键点数据、训练与评测脚本、模型文件及实验报告。
