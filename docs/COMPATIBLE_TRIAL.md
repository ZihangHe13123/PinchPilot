# v0.11.0 兼容定位试用

这版继续使用你已经习惯的拇中捏合点，让整手平移与自然转腕在同一个模式里操作。它沿用镜像预览中的位置方向，不需要中立/向右/向上的方向校准。

## 开始使用

1. 按 Esc 停止并退出旧窗口，重新打开 `launch_desktop_mac.command`，确认标题为 **0.11.0**。Windows 源码入口是 `launch_desktop_windows.cmd`。
2. 展开「手感设置」，确认「定位方式」为 **兼容定位 · 平移＋转腕**。全新配置默认此模式；旧腕动配置第一次升级会切换并提示。已有位置配置保留原选择，可手动切过来。
3. 支撑前臂，把手放在镜头能看清的舒适位置，启动相机，再手动启用鼠标。拇中捏住、食指分开后即可接管。
4. 先用原来的灵敏度试。转腕与小幅平移可以自然混用，不必保持手掌朝向完全不变，也不需要切换模式。想换手位时松中指，光标冻结，再捏回继续。

食拇左键/双击/保持拖拽、拇无名指右键、V 手势滚轮、拖拽时松中指回位的动作继续沿用。明确松开中指立即冻结；短暂识别不稳时先暂停移动，捏稳后原地继续，期间不会补走一段位移。接触在握持不稳时开始会要求先分开点击手指，避免误点。

兼容定位固定使用精细滤波和恒定增益，灵敏度与抗抖仍可调整；旧的自适应模式选择保存下来，切回「指尖位置 · 原版对照」时恢复。旧腕动方向参数也保留，但不参与兼容定位。两种旧校准面板在此模式隐藏。

## 建议先比较这几个动作

每项约半分钟，保持相同的灵敏度与机位：

| 动作 | 重点观察 |
|---|---|
| 整只手向左/右/上/下平移 | 是否仍和以前一样直观、准确 |
| 前臂支撑，手腕带动手端做小幅移动 | 是否同向、是否还需要绷住整个手臂 |
| 平移过程中自然转腕，再转回 | 是否突然加速、跳动或断触 |
| 停到小按钮，微调后点击/双击 | 是否跟得上，是否有新增的迟缓或误点 |
| 拖动窗口，松中指回位再继续 | 光标是否原地等待；松食指是否放下 |

可以随时切回「指尖位置 · 原版对照」比较；切换会先停止控制，需要手动重新启用。旧「腕动角度 · 旧实验」也保留，仍要求方向校准。

## 这次改动的边界

指针仍根据画面中的实际移动量控制，没有给平移额外叠加转角。掌部五点只提供小幅防抖辅助，修正最多3个逻辑像素，质量不足就退回实际捏合点。握持单独使用三维尺度，同时用画面中明显分开的指尖否决假捏合；左右点击继续原有距离定义。这有助于避免掌部转侧造成的握持比例变化，不代表严重遮挡或深度估计错误已经解决。

恒定增益能消除速度曲线带来的距离差异，但镜头投影仍然存在：同样转角在不同手位不一定产生同样画面位移，朝镜头前后移动也不能凭空变成可靠的上下/左右控制。手必须可见；严重遮挡、控制手不明确、真实丢手与停流仍按原规则停止并松键。

自动验证使用生成关键点、模拟鼠标和离屏界面，不能证明真人疲劳或真实识别率改善。用户已初步反馈比此前更舒适，尚不代表多用户或长时间验收。当前更新同时提供 v0.11.0 Mac/Windows 便携归档；先前的 v0.8.1 ZIP 保持原样，Windows 真机仍待测试。
