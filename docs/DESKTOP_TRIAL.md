# PinchPilot 0.8 桌面测试版

此入口把已体验的拇中定位、食拇左键/拖拽、拇无名指右键接到真实系统鼠标。v0.8 新增连续灵敏度滑条与 V 手势滚轮，默认移动速度、滤波和抗抖保留。支持单手、主屏幕；尚未加入跨屏或专门的双击识别。

## 启动和接管

1. 先退出占用相机的旧 Demo。Mac 双击 `launch_desktop_mac.command`；Windows 双击 `launch_desktop_windows.cmd`。命令行可执行 `uv run pinchpilot desktop`。
2. 点「启动相机」，支撑前臂，让相机看清整只手和指尖。相机编号可在「展开手感设置」中调整。
3. 有实时画面后，点「启用鼠标控制」。从此时的系统光标位置接管，不跳回屏幕中心。
4. 食指先移开，拇中轻捏约 0.12 秒后开始移动。停止后再次启用、丢手后重新接管，都需要这一步。
5. **Esc 在其他应用前台也可停止控制**。窗口里的「停止控制」作用相同，相机仍可预览；「停止相机」和关窗同时停止控制并释放按键。

启动不会自动开相机或接管鼠标，也不会记住上次的启用状态。可最小化窗口继续使用；关闭预览只减少绘图，不停止摄像头。关窗退出程序，没有隐藏到托盘。一个工作目录只允许一个桌面测试窗口运行。

Mac 首次使用可能需要给实际启动程序的 Terminal / 应用授予摄像头、辅助功能、输入监控权限，按窗口提示到系统设置授权并重启。Windows 需允许桌面应用访问摄像头；先在普通权限窗口操作。脚本按 `uv.lock` 安装依赖，模型首次下载后缓存本机。具体环境安装见项目 README。

## 手势

| 操作 | 动作 |
|---|---|
| 移动 | 拇指＋中指捏住，小幅移动捏合点 |
| 左键 | 食指＋拇指短捏，再松食指 |
| 右键 | 食指先分开，无名指先离开拇指片刻，再轻捏拇指＋无名指 |
| 拖拽 | 食拇捏住，按下后约 0.30 秒、进度环满，再保持捏合移动；松食指放下 |
| 滚轮 | 食指和中指做 V，无名指/小指弯曲，拇指与指尖分开；保持片刻后上下轻移，收指结束 |
| 锁定后点 | 松中指锁住光标，仍可食拇左击或拇无名指右击 |
| 换位续拖 | 拖拽中保持食拇捏合，松中指换手位，再捏中指继续 |

右键、拖拽和滚轮可分别关闭。更改手势参数会先关闭鼠标控制，调整后再次启用；「重新定位」也先停止控制，重新启用后从当前系统光标接管。设置保存在 `data/desktop-settings.json`。

## 灵敏度和滚动怎么调

点「展开手感设置」，移动灵敏度使用 **0.10×～2.00×** 滑条。向左更慢，步进 0.01×；1.00× 对应原默认的 30%，旧最慢档 40% 对应 0.75×，旧快档 20% 对应 1.50×。如果旧最慢档仍快，可以先试 0.50× 或 0.30×。拖动中只显示预览值，松手才应用；键盘左右键每次改变一步。「恢复默认」回到 1.00×，不会更改抗抖等设置。旧配置会自动转换，低倍率下可松中指换位继续移动。

V 手势时拇指要与食指、中指、无名指指尖分开，以区分已有捏合动作。保持约 0.18 秒，再有约画面高度 1.5% 的纵向位移后进入 `SCROLL`；形成姿态与启动阶段的移动不翻页。静止摆 V 不抢走锁定后的点击。进入滚动后光标固定，上移向上翻、下移向下翻，手停下就停；收回 V 后重新捏中指接管指针。拖拽期间不发送滚轮。

「滚动速度」有慢、标准、快三档，独立于指针灵敏度。抗抖、左右接触阈值和拖拽等待继续独立调整。灵敏度不是识别置信度，降低倍率不会自动修复追踪错误。

## 数据和开关

| 显示或记录 | 含义 |
|---|---|
| 处理帧率 | 最近两秒实际消费的新帧数按时间计算；超过 0.25 秒无新鲜帧显示 0，不把 UI 刷新当相机 FPS |
| 推理耗时 | 最近一帧手部模型调用耗时；日志另含最近最多 180 帧的 P95 |
| 读帧后帧龄 | 相机读取完成到当前时刻的间隔；不包含相机曝光/硬件缓冲、OS 显示耗时，不是端到端延迟 |
| 手部跟踪、丢失 | 有效手部特征是否存在，以及从跟踪到缺失/过期的次数；主动切换来源不计掉手 |
| 左、右、拖 | 原生接口成功返回的按下次数，以及进入拖拽状态的次数；不能当成应用内成功率 |
| 本次运行 | 当前窗口持续运行时间，包括预览和暂停；不是有效操控时长 |
| 滚轮发送 | 实际进入原生滚轮调用的次数；未累计到一整行的内部请求不计，不代表页面已翻动的距离或成功率 |
| 状态与按键 | 手势状态机和系统适配器记录的按住状态分开显示；未启用时识别手势不会发送按钮 |

默认开启「保存本地测试记录」，约每秒写一次性能摘要，另写来源、参数、状态变化、原生按钮计数和停止原因。只保存在 `reports/desktop_trials/trial_*.jsonl`；「打开测试记录」可查看。**不保存相机图像、视频、关键点、输入文本或应用/窗口标题，不上传。** 关闭记录后不再写入；再次打开会创建新文件。计数按当前窗口累计，日志切分并不重置计数。

合成演示始终禁止真实鼠标，画面和日志标记来源，不用来评估相机帧率或真人效果。桌面记录也不是训练数据。需要目标任务、静止抖动测量或原有采集训练时，使用 `launch_tripod_mac.command` / `launch_tripod_windows.cmd` 打开研究界面；原实验模式仍限于应用内。

## 中断行为

缺手、跳变或换手会取消引擎中的按住并要求重新接管；无新鲜画面超过约 0.25 秒会关闭鼠标控制。后台线程每约 40 ms 检查 Esc 和界面心跳；界面超过约 0.40 秒不响应时，停止后续输出并尝试松键。松键调用失败会保留状态、显示错误并重试，未释放前不允许重新启用。

这些是进程正常运行且原生调用可返回时的处理，不保证系统崩溃或进程被强杀时完成松键。取消时的 mouse-up 也不能撤销目标应用已经收到的操作。

## 数日试用怎么记

先保持默认参数做正常的点击、右键和拖拽；不必持续抬手长时间测试。遇到不舒服或操作异常，记录大致时间、操作、是否误点/漏点/掉手，以及是否改过设置。结合本地日志才能区分识别问题、画面停顿和手感取舍。日志没有你本来的操作意图，不能自动推算误触率或准确率。

当前提供源码启动脚本、wheel 和 sdist，尚非签名的 `.app` / `.exe` 安装器。自动化、离屏 GUI、原生接口模拟及 Mac 只读权限检查见 [验证记录](VALIDATION.md)；真人数日稳定性、真实桌面注入与 Windows 硬件需实际试用验收。
