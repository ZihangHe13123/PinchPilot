# PinchPilot 0.11.0 桌面测试版

此入口把已体验的拇中定位、食拇左键/拖拽、拇无名指右键接到真实系统鼠标。v0.11.0提供免方向校准的「兼容定位 · 平移＋转腕」，作为全新桌面配置的默认方式；旧腕动配置首次升级会切换并提示，原位置配置保留。详见 [COMPATIBLE_TRIAL.md](COMPATIBLE_TRIAL.md)。原位置模式、旧角度实验、画面边缘提醒、连续灵敏度、V手势滚轮、双击与控制手锁定均保留。支持一只控制手、主屏幕，Windows真机仍待验收。

## 启动和接管

v0.11.0 兼容定位已纳入两平台便携归档，源码入口也可继续使用。旧 v0.8.1 ZIP 和旧对照报告原样保留。先按 Esc、退出旧窗口，再从新归档或源码入口打开，确认标题为 0.11.0。

Mac 便携归档：M 系列 Mac（macOS 14+）解压 `PinchPilot-0.11.0-macOS-arm64.zip` 后双击 `Start.command`，从下面第 2 步继续，无需 uv；见 [Mac 归档说明](MACOS_ARCHIVE.md)。

Windows 便携包：先全部解压 `PinchPilot-0.11.0-Windows-x64.zip`，双击 `Start.cmd`，之后从下面第 2 步开始。包内已含运行时、依赖和模型，详细步骤与故障诊断见 [Windows 试用说明](WINDOWS_TRIAL.md)。下面的 `launch_*` 脚本适用于源码环境。

1. 先退出占用相机的旧 Demo。Mac 双击 `launch_desktop_mac.command`；Windows 双击 `launch_desktop_windows.cmd`。命令行可执行 `uv run pinchpilot desktop`。
2. 右侧「控制手」默认自动锁定，先只露出要操作的一只手，点「启动相机」，看到「已锁定右手 / 左手」后另一只手可入镜。也可提前选择「只用右手 / 只用左手」。支撑前臂，让相机看清整只手和指尖；相机编号在「展开手感设置」中调整。
3. 有实时画面后，点「启用鼠标控制」。从此时的系统光标位置接管，不跳回屏幕中心。
4. 食指先移开，拇中轻捏约 0.12 秒后开始移动。停止后再次启用、丢手后重新接管，都需要这一步。
5. **Esc 在其他应用前台也可停止控制**。窗口里的「停止控制」作用相同，相机仍可预览；「停止相机」和关窗同时停止控制并释放按键。

启动不会自动开相机或接管鼠标，也不会记住上次的启用状态。可最小化窗口继续使用；关闭预览只减少绘图，不停止摄像头。关窗退出程序，没有隐藏到托盘。一个工作目录只允许一个桌面测试窗口运行。

Mac 首次使用可能需要给实际启动程序的 Terminal / 应用授予摄像头、辅助功能、输入监控权限，按窗口提示到系统设置授权并重启。Windows 需允许桌面应用访问摄像头；先在普通权限窗口操作。脚本按 `uv.lock` 安装依赖，模型首次下载后缓存本机。具体环境安装见项目 README。

## 手势

| 操作 | 动作 |
|---|---|
| 移动 | 拇指＋中指捏住，小幅移动捏合点 |
| 左键 | 食指＋拇指短捏，再松食指 |
| 双击 | 光标到位后连续食拇短捏两次，中间明确松食指；也可松中指锁住位置再双击 |
| 右键 | 食指先分开，无名指先离开拇指片刻，再轻捏拇指＋无名指 |
| 拖拽 | 食拇捏住，按下后约 0.30 秒、进度环满，再保持捏合移动；松食指放下 |
| 滚轮 | 食指和中指做 V，无名指/小指弯曲，拇指与指尖分开；保持片刻后上下轻移，收指结束 |
| 锁定后点 | 松中指锁住光标，仍可食拇左击或拇无名指右击 |
| 换位续拖 | 拖拽中保持食拇捏合，松中指换手位，再捏中指继续 |

右键、拖拽和滚轮可分别关闭。更改手势参数会先关闭鼠标控制，调整后再次启用；「重新定位」也先停止控制，重新启用后从当前系统光标接管。设置保存在 `data/desktop-settings.json`。

## 画面边缘提醒与换位

识别使用完整的镜像相机画面；预览虚线是指针映射范围，**不是检测裁剪框**。扩大虚线或切换移动模式不会使相机看见原本画面外的手。手常从下沿或两侧离开时，先调整屏幕角度，让取景覆盖前臂有支撑时的手位；更改分辨率也不保证获得更大视场。

「画面边缘提醒」默认开启，可关闭并保存偏好。程序只观察已选定控制手的拇、食、中、无名指指尖和四个掌指关节，接近真实画面四边时显示状态与黄色边条；腕点、小指尖不参与判断，减少自然支撑姿势下的误报。约进入距边缘8%的范围并保持0.12秒后提示，退回12%内侧并保持片刻后清除，减少反复闪烁。

启用鼠标控制时，小型置顶提示在主窗口最小化后仍可显示；按不抢焦点、鼠标穿透的方式实现，实际平台表现仍需真机试用。关闭提醒不会改变光标或按钮处理。停止控制、相机停流或退出时浮动提示隐藏；静止校准期间固定状态、边条和浮动提示均隐藏，避免干扰静止要求。

| 当前动作 | 看到边缘提示后的换位方式 |
|---|---|
| 普通移动 | 松中指冻结光标，将手移回画面内，再捏住中指继续 |
| 正在完成点击 | 先完成当前点击，再松中指换位 |
| 拖拽 | 保持食拇捏合，只松中指，将手移回后再捏中指续拖 |
| 滚动 | 先收回 V 手势，再移回画面内，重新做 V 继续 |

提醒只提供反馈，不强制停止、自动加速或修改 v0.9.0 的映射与滤波。收到缺手结果时仍立即按原逻辑释放按键；拖拽已因丢手结束就不能在画面外续拖。恢复可见后，先分开食指，再正常捏合接管。缺手也可能来自遮挡或识别不稳定，提示不把它断言为一定出了画面。具体几分钟试用清单见 [CAMERA_FRAMING_TRIAL.md](CAMERA_FRAMING_TRIAL.md)。

## 双击与另一只手

双击沿用系统双击时间窗口：Mac 读取当前系统设置，正确发送第二次按下/释放的双击标记；Windows 由系统处理连续输入。每次短捏后食指需与拇指明显分开，长时间捏住会进入拖拽。先试在同一位置短捏—松开—短捏—松开，可用文本里的一个词检查是否被双击选中；单击立即输出，不需要等双击超时。

自动模式锁定后不会因为控制手离开而改选另一侧。控制手丢失、双手太近或左右手分类不明确时暂停并释放按键；手回到清楚可见的位置后，先移开食指，再捏住拇中接管。左右手锁定依据模型分类和掌部连续性，严重遮挡或误分类仍需实际验证，不能保证双手交叉时完全不受影响。

更改「控制手」会停止相机和鼠标控制，重新启动后生效。自动模式若选错手，停止相机、只露出希望使用的手再启动；也可以直接指定左右手。设置会记住选择偏好，运行中的锁定状态不会跨启动保存。

## 灵敏度和滚动怎么调

「展开手感设置」先选择「定位方式」。兼容定位固定使用精细滤波、无需校准；旧腕动角度实验固定精细并需方向校准。「指尖位置 · 原版对照」下仍可选择以下「移动模式」：

| 模式 | 用途与取舍 |
|---|---|
| 原版 · 对照（classic） | 保留 v0.8.2 移动方式；较强的静止抑制也可能让细小修正不响应 |
| 精细 · 小幅微调（precise） | 桌面新配置默认；较小的屏幕尺度死区和较快滤波，优先改善微调与停止响应，静止波动可能更多 |
| 自适应 · 实验（adaptive） | 在精细处理基础上随速度改变增益；慢速细调、快速跨越，需重新适应移动距离 |

切换模式会先停止鼠标控制，手势定义不变。位置对照下，已有旧版设置但没有移动模式字段时保留经典手感；保存的模式照常恢复。兼容定位保留旧选择供切回时使用。详细位置对照顺序见 [移动调优试用](MOTION_TUNING_TRIAL.md)。

点「展开手感设置」，移动灵敏度使用 **0.10×～2.00×** 滑条。向左更慢，步进 0.01×；1.00× 对应原默认的 30%，旧最慢档 40% 对应 0.75×，旧快档 20% 对应 1.50×。如果旧最慢档仍快，可以先试 0.50× 或 0.30×。拖动中只显示预览值，松手才应用；键盘左右键每次改变一步。「恢复默认」回到 1.00×，不会更改抗抖等设置。旧配置会自动转换，低倍率下可松中指换位继续移动。

V 手势时拇指要与食指、中指、无名指指尖分开，以区分已有捏合动作。保持约 0.18 秒，再有约画面高度 1.5% 的纵向位移后进入 `SCROLL`；形成姿态与启动阶段的移动不翻页。静止摆 V 不抢走锁定后的点击。进入滚动后光标固定，上移向上翻、下移向下翻，手停下就停；收回 V 后重新捏中指接管指针。拖拽期间不发送滚轮。

「滚动速度」有慢、标准、快三档，独立于指针灵敏度。抗抖、左右接触阈值和拖拽等待继续独立调整。灵敏度不是识别置信度，降低倍率不会自动修复追踪错误。

## 6 秒静止校准

1. 先选精细或自适应模式，启动实时相机并让控制手清晰可见；原版和合成演示不能进行此校准。
2. 支撑前臂，拇中轻捏，食指和无名指移开；点「6 秒静止校准」。程序会关闭鼠标控制并释放按键。
3. 准备1秒后，保持捏合点尽量静止5秒。不要为“跟住光标”而移动手；此时没有系统鼠标输出。
4. 查看成功或拒绝提示；「采集时波动」是本次采集的估计，不是当前实时抖动。完成、取消、失败后鼠标都保持关闭。需要时手动点「启用鼠标控制」，再捏合接管。

校准测量的是当前机位、姿势与设置下的静止波动，不训练模型、不识别你的真实动作意图。样本不足、失手、采样中断、持续漂移或波动过大时不应用，保留原有参数。换了姿势、机位或支撑方式，可重新采集；「清除静止校准」清除估计并停止控制，不会自动恢复输入。

精细/自适应在**标准抗抖档**的默认软死区半径为2个逻辑屏幕坐标单位，校准后的基础半径最多4；这是增益前的尺度，不是所有档位的最终输出上限。「强」档仍乘抗抖倍率，可达到7，因此更可能抑制小修正。校准可以减少静止波动，但不能保证更好点中小目标；同时比较抖动和反向微调，不要只看数字变小。

## 数据和开关

| 显示或记录 | 含义 |
|---|---|
| 处理帧率 | 最近两秒实际消费的新帧数按时间计算；超过 0.25 秒无新鲜帧显示 0，不把 UI 刷新当相机 FPS |
| 推理耗时 | 最近一帧手部模型调用耗时；日志另含最近最多 180 帧的 P95 |
| 读帧后帧龄 | 相机读取完成到当前时刻的间隔；不包含相机曝光/硬件缓冲、OS 显示耗时，不是端到端延迟 |
| 手部跟踪、丢失 | 有效手部特征是否存在，以及从跟踪到缺失/过期的次数；主动切换来源不计掉手 |
| 左、右、拖 | 原生接口成功返回的按下次数，以及进入拖拽状态的次数；不能当成应用内成功率 |
| 本次运行 | 当前窗口持续运行时间，包括预览和暂停；不是有效操控时长 |
| 滚轮发送 | 实际进入原生滚轮调用的次数；未累计到一整行的内部请求不计，不代表页面已翻动的距离或成功率 |
| 状态与按键 | 手势状态机和系统适配器记录的按住状态分开显示；未启用时识别手势不会发送按钮 |

默认开启「保存本地测试记录」，约每秒写一次性能摘要，另写来源、参数、状态变化、原生按钮计数、停止原因及成功静止校准的估计摘要。只保存在 `reports/desktop_trials/trial_*.jsonl`；「打开测试记录」可查看。**不保存相机图像、视频、关键点、输入文本或应用/窗口标题，不上传。** 校准样本仅在内存中处理，设置文件只保存估计参数及开关；新增边缘提醒不增加图像或关键点落盘。关闭记录后不再写入；再次打开会创建新文件。计数按当前窗口累计，日志切分并不重置计数。

合成演示始终禁止真实鼠标，画面和日志标记来源，不用来评估相机帧率或真人效果。桌面记录也不是训练数据。需要目标任务、静止抖动测量或原有采集训练时，使用 `launch_tripod_mac.command` / `launch_tripod_windows.cmd` 打开研究界面；原实验模式仍限于应用内。

## 中断行为

缺手、跳变或换手会取消引擎中的按住并要求重新接管；无新鲜画面超过约 0.25 秒会关闭鼠标控制。后台线程每约 40 ms 检查 Esc 和界面心跳；界面超过约 0.40 秒不响应时，停止后续输出并尝试松键。松键调用失败会保留状态、显示错误并重试，未释放前不允许重新启用。

这些是进程正常运行且原生调用可返回时的处理，不保证系统崩溃或进程被强杀时完成松键。取消时的 mouse-up 也不能撤销目标应用已经收到的操作。

## 数日试用怎么记

先保持默认参数做正常的点击、右键和拖拽；不必持续抬手长时间测试。遇到不舒服或操作异常，记录大致时间、操作、是否误点/漏点/掉手，以及是否改过设置。结合本地日志才能区分识别问题、画面停顿和手感取舍。日志没有你本来的操作意图，不能自动推算误触率或准确率。

当前提供 Windows 便携 ZIP、源码启动脚本、wheel 和 sdist，尚非签名的 `.app` / `.exe` 安装器。自动化、离屏 GUI、原生接口模拟及 Mac 只读权限检查见 [验证记录](VALIDATION.md)；真人数日稳定性、真实桌面注入与 Windows 硬件需实际试用验收。
