# PinchPilot 0.11.0 — Mac 归档包

适用：Apple Silicon Mac（M 系列），macOS 14 或更新版本。
这是和 Windows 测试包对应的 v0.11.0 应用归档，默认使用「兼容定位 · 平移＋转腕」，
无需方向校准；保留灵敏度滑条、V 手势滚轮、左键、双击、右键、拖拽与抗抖。
不是 Intel Mac / 通用架构版本。旧 v0.8.1 ZIP 单独保留，不覆盖。

## 使用

1. 用 Finder 双击 ZIP 全部解压，保留整个文件夹；不要只复制启动脚本。
2. 双击 Start.command。包内已经带齐 Python、依赖和模型，无需安装 uv，
   也不依赖原项目目录的虚拟环境。退出程序请关闭 PinchPilot 窗口。
3. 点「启动相机」，看到画面后再点「启用鼠标控制」。
4. 食指移开，拇指＋中指轻捏接管指针。按 Esc 随时停止控制。

确认窗口标题为 0.11.0。「兼容定位」允许整手平移和自然转腕连续混用，固定精细
滤波，灵敏度仍可调。当前干净归档不需要先做校准；旧角度实验和原位置模式保留作
对照，详见 docs/COMPATIBLE_TRIAL.md。

启动时相机和控制都关闭。建议先退出占用相机的旧窗口，支撑前臂后操作。
Mac 可能要求给 Terminal 或实际启动程序授予摄像头、辅助功能、输入监控权限；
按程序提示到「系统设置 → 隐私与安全性」授权并重新启动。本归档不修改系统权限。
这是便携目录，不是开发者签名、公证的 .app 安装器。如果系统阻止打开，从文件
右键菜单选择「打开」并按系统提示确认；不需要关闭系统安全功能。

## 手势与设置

| 操作 | 动作 |
|---|---|
| 移动 | 拇指＋中指捏住，小幅移动捏合点 |
| 左键 | 食指＋拇指短捏，松开食指 |
| 右键 | 食指分开，无名指先离开拇指片刻，再与拇指轻捏 |
| 拖拽 | 食指＋拇指捏住，等约 0.30 秒，再保持捏合移动；松食指放下 |
| 滚轮 | 食指＋中指做 V，无名指/小指弯曲，拇指分开；保持片刻后上下轻移 |
| 恢复移动 | 收回 V，再捏拇指＋中指 |
| 停止控制 | Esc，或窗口里的「停止控制」 |

展开「手感设置」可调 0.10×～2.00× 移动灵敏度。松开滑条后应用，再启用控制。
右键、拖拽、滚轮有独立开关；滚动速度单独调整。详细手势见 docs/DESKTOP_TRIAL.md。

## 诊断和记录

- Demo.command：合成演示，不开相机、不控制鼠标。
- Diagnose.command：检查包内依赖、模型 CPU 推理与短暂演示窗口；不操作相机
  或系统鼠标，不修改日常手感设置。结果保存在 reports/diagnostics/。
- 启动错误：reports/startup/。试用数据：reports/desktop_trials/。
- 设置：data/desktop-settings.json。初始归档没有复制开发机设置或试用记录。
- 日志不保存摄像头图像、视频、关键点、输入文本或应用标题，不自动上传。
  诊断可能含本机用户名路径，发给别人前可以自行检查。

本机验收使用重新解压的包内 Python，检查依赖隔离、中文/空格路径、模型推理和
演示窗口。没有为归档检查再次开启摄像头或注入系统输入；权限与真人操作体验
沿用正常试用流程。未验证所有旧版 macOS；目标最低版本由所选依赖的发布标签确定。

## 留档与复现

- BUILD_INFO.json：应用版本、源码提交、Python/依赖/模型版本与来源。
- FILES.sha256：普通文件校验值；SYMLINKS.json：运行库符号链接及目标。
- source/PinchPilot-0.11.0-source.zip：对应提交的源码快照，包括构建脚本和依赖锁。
- docs/THIRD_PARTY.md 和运行库内的 license/notice：第三方组件声明。
- 外层 ZIP 旁的 .sha256 文件：检查整个归档在复制后是否完整。

建议保留原始 ZIP 和 .sha256 文件作为干净归档，在解压副本里试用。整个文件夹
可以移动位置；再次分发原始 ZIP 就不会混入后来产生的个人设置和试用日志。
