# 食拇点击与松中指后锁定点击

日期：2026-09-21。用户反馈 v0.4 移动舒服，但点击不够灵敏，提出改为食指碰拇指，并允许到位后松开中指再点。本轮沿用其具体方案与此前尽可能推进的授权。

## 范围与取舍

采用食指—拇指距离作为点击依据，拇指—中指仍只负责接管移动。相比放宽旧三指同时接触阈值，这能取消不必要的中指点击条件；相比新增第二个点击模式，同一套操作即可覆盖保持中指捏合点击和松开中指后点击。

保留 v0.4 的中点定位、30% 默认范围、中值滤波、自适应低通与死区参数。确认时长和点击阈值先不变，只改变点击参照和移动/点击的衔接。界面预览的点击虚线改连食指和拇指。

## 交互与状态

1. 初始仍须拇中捏住、食指移开约 0.12 秒才能接管。初始只做食拇捏合不触发点击。
2. 拇中保持捏合时，食拇接近先冻结指针，达到接触阈值约 0.06 秒后单击。保持接触不连点，分开确认后重新允许点击。
3. 松开中指立即锁住当前位置，进入 `FROZEN`；继续观察食拇距离，允许反复主动点击。松中指本身不输出移动或点击。此时相机里的捏合中点变化不再控制光标。
4. 若松中指的当帧食拇已经靠拢，取消尚未确认的点击并提示先分开（`WAIT_CLEAR`），避免把切换过程当成一次点击。已经点击的 `TOUCHED` 保持锁存，松/合中指不能造成重复点击。
5. 锁定后，食指移开并重新捏住拇中约 0.12 秒，按当前手位重设参照，光标从原位置继续。重新接管期间不跟随中点移动。
6. 松中指只锁定位，不是完全停用；Esc、丢手、暂停、异常时间、换手或明显掌部跳变取消点击资格。没有隐藏的锁定倒计时。

移动中的中点跳变保护继续保留；松中指/重新捏合时中点会自然改变，改用掌部位置与手别检查追踪连续性，不把中指伸展误判为丢失追踪。掌部坐标只参与跳变检查，不进入定位。

## 实现与验证

- 只调整三指引擎、合成手势、相关界面提示和说明；仍为应用内 Demo，原捏合和历史单指保留。
- 模式名保留 `tripod`，版本升至 v0.5.0。日志已有 `app_version`，文档明确 v0.5 的 `contact` 改为食拇距离，旧版本记录不能直接混算。
- 覆盖保持拇中点击、松中指后点击、松开当帧取消、保持不连点、再次点击、重新定位无跳变、中指大幅伸展、丢手/换手/暂停与冻结诊断排除。
- 两条点击路径分别通过应用内八目标合成任务；用相同噪声与种子核对 v0.4/v0.5 连续移动输出不变，并查看界面截图。
- 完成单元/界面检查、打包和从 wheel 启动验证。不自动打开摄像头、注入系统鼠标或重启正在运行的旧实例。

用户对 v0.4 的评价仅作为主观试用反馈；合成检查用于验证逻辑，不代表真实点击成功率。v0.5 还需用户重启后确认点击手感。
