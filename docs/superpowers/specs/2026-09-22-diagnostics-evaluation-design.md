# 0.12 诊断与可重复评估

用户已同意直接推进无需额外数据的工程工作。保留已确认舒适的 0.11 兼容定位、阈值、滤波和手势时序，本轮增加观察与测试工具。

## 交付范围

1. 状态原因诊断：控制手选择、捏合不稳定暂停、点击冻结、松中指锁定等只读原因；记录原因切换和持续时间。不能从现有观测确定的原因明确标为未知，不推断用户意图。
2. 问题标记：保留最近约 10 秒不含图像、关键点或桌面坐标的诊断摘要，用户按按钮标记“刚才抖动/迟滞/点击/丢手”等问题后保存上下文。关闭一般日志时，显式标记仍可单独保存，且不会重新开启日志。
3. 延迟分段：相机 read 调用、图像预处理、模型推理、推理完成到 GUI 接收、引擎处理和本地鼠标发送耗时；记录最新结果槽覆盖次数。时间范围清楚，不把它称为传感器到屏幕的端到端延迟。
4. 内置测试台：固定点击、双击、拖拽、反向微调、滚动停止任务，用引擎虚拟输入评分；打开时停止系统鼠标，关闭后需手动重启控制。合成演示结果单独标识。记录任务成功、耗时和操作偏差，不宣称日常识别准确率。
5. 离线对比：同一输入比较兼容定位、精细位置与经典位置；可用固定种子合成轨迹，无需新数据，也能读既有标注录制。输出定义明确、可重复的 JSON，可选逐帧结果。

## 边界与验证

不自动打开相机，不注入真实系统输入做测试，不改用户现有设置，不重新打包或覆盖 0.11 归档。没有真实标注数据便不声称 ML 改善；本轮不训练模型。

纯模型、FakeMouse、离屏 Qt 验证诊断不改变操作；测试台隔离、停止与恢复；标记隐私与日志关闭语义；各阶段计时缺失值；离线确定性与无系统输入。最后运行现有回归测试和合成对比，保存报告与使用文档。实际相机手感、Windows 真机体验留待下一轮试用。
