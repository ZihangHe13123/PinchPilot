# 兼容定位：整手平移与自然转腕

用户目标是延续已有拇中定位手感，让前臂放松后的转腕微调也能连续使用；独立角度校准不符合这个目标。当前链路未发现重复镜像，原腕动实验的相机坐标旋转轴会受示范动作与实际姿态差异影响。

本轮增加 `unified` 定位方式，不使用腕动方向校准，也不叠加角度位移。实际拇中中点的画面方向是基准，恒定增益的精细滤波处理平移、转腕和混合动作，避免自适应速度增益造成不同动作速度的手感变化。现有位置模式保留作对照，旧角度实验保留但不作为新默认。

掌部二维相似变换只用于估计同一个捏合点：接管时保存掌部五点与实际中点；运行时拟合平移、画面内转动和缩放，计算虚拟点，滤波实际点相对虚拟点的残差。修正总长度最多 3 个逻辑像素，之后仍经过现有指针滤波。它不是额外的运动来源；不从 MediaPipe 深度估计推导指针方向。拟合不可靠时退回实际点，不因此解除接管。不补偿不可观测的深度位移，不承诺不同机位下角度与光标距离完全一致。

握持距离单独使用与指尖距离相同单位的三维掌部尺度，减少转侧后二维分母缩短带来的误松手。二维指尖距离/二维掌尺度另作可见分离否决：接管不高于0.46，明显分离达到0.64立即松开，避免估计深度异常掩盖张开的手指。左右点击距离继续使用既有比例，避免无意放宽按键触发。轻微越过松手阈值时立即暂停指针，最多等待 80 ms 判断是否持续；短暂恢复后原地重锚，不补走不可靠期间的位移。宽容期不累计新点击，已有左键仍可松开。明显松开立即执行原有离合。真实丢手、时间中断、身份切换仍沿原路径松键。

桌面全新设置默认兼容定位；旧位置设置保留。旧腕动设置首次升级迁移到兼容定位并显示提示，保留旧校准与其他参数，之后用户主动选择的模式正常保存。切换模式始终先停止系统输入，重新开启由用户完成。兼容定位隐藏两种旧校准，不读取其噪声或方向参数。

验收包括理想刚性平移/转腕/混合动作方向与位移、不重复计数、速度终点一致、残差噪声抑制、仅深度噪声不移动、拟合退化回退、姿态握持与真实松开、点击/右键/拖拽/滚动及缺帧松键、设置迁移和无系统输入的 UI 检查。合成输入只验证机制；舒适度、真实跟踪精度和 macOS/Windows 摄像头手感需要用户实测。
