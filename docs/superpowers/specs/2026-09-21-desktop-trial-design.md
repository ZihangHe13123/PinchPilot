# 可用于实际鼠标的桌面测试版

2026-09-21：用户认可 v0.6 右键与拖拽体验，明确授权“做成测试版的工具，显示必要测试数据和开关，能操控鼠标”。此前等待真人认可的条件已满足。本轮实现 v0.7，沿用已认可的 TripodEngine 手势、移动范围、滤波和抗抖。

## 入口与界面

采用单独的轻量桌面窗口，不把日常试用和旧采集/训练页面混在一起。另两个选项是继续在实验室页面开放开关，或直接做无窗口托盘；前者日常控件过多，后者不便观察问题，因此首版保留紧凑窗口。

- 提供 Mac/Windows 启动脚本和 `pinchpilot desktop`。启动不自动读相机或接管鼠标，真实控制必须由界面明确启用。
- 显示相机预览、手势状态、左右按钮/拖拽状态、处理 FPS、推理耗时、帧龄、跟踪丢失次数和本次成功发送的按钮次数。显示来源，合成演示绝不能启用真实鼠标。
- 主开关：相机、系统控制、紧急停止；设置：预览、置顶、右键、拖拽、本地测试记录。已有范围/抗抖/触碰/拖拽等待参数可折叠调整。设置持久化，启动与控制状态不持久化。
- 处理帧率仅对实际新帧计算，推理耗时和读帧后的帧龄不称作端到端延迟或准确率。没有真人标签，不显示虚构 accuracy。

## 控制与中断

新窗口直接使用共享 TripodEngine 与 Mac/Windows MouseOutput，原实验室的隔离边界保留。启用时检查真实相机新鲜帧与平台权限，读取当前系统指针，再重新接管，避免跳回中央。左右键、拖拽按 v0.6 运行；右键/拖拽可独立关闭。调整影响手势的设置先停用系统控制。

系统输出封装为独立的受控会话，用锁串行发送/关闭。后台看门狗检查全局 Esc 和主界面心跳；即使窗口最小化、失焦或主循环停顿，也能停止后续输入并尝试释放按键。相机中断、过期结果、切演示、暂停、停止、异常与关窗都结束按住。关闭失败保留错误并允许再次清理，不把释放失败当作成功。

相机缺手由引擎取消按住并重新接管；无新鲜帧时关闭系统输出。恢复/再次启用会读取当前系统鼠标位置。冻结位置时仍遵循原手势语义，不新增未经体验的指针加速或自动物理鼠标接管判断。

## 本地数据与交付

只保存本地会话配置、性能采样、状态/按钮事件与停止原因，不保存图像、视频、按键内容、应用或窗口标题。提供记录开关和打开记录目录。每个新会话独立记录，指标明确区分输出成功与识别意图；不把按钮计数当成功率。

依赖、模型复用当前环境，保留旧版本与研究界面。测试版是源码/启动脚本与 Python 安装包，不冒充已签名原生安装器。Windows 使用同一核心与既有适配器，仍需 Windows 真机验收。

## 验证

覆盖新开关、权限/来源/新鲜度门控、从真实指针接管、左右键/拖拽到模拟系统适配器、控制关闭后不得再输出、后台 Esc、心跳超时、过期与缺失、异常释放、关闭/设置/演示生命周期、本地记录开关与恢复设置、最小化保持心跳。保留旧版完整回归与指定噪声轨迹对照，离屏查看紧凑窗口、打包并从 wheel 启动。

真实 Mac 只读核对权限/API；不在用户现有桌面盲目点击或开启相机。若执行真实输入检查，范围必须限定在自建测试窗口并能明确验证焦点；未执行时如实标记，由用户启动后实际试用。新版本不宣称已完成数日稳定性或真人准确度实验。
