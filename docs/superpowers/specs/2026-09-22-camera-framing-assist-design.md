# 画面边缘提醒与换位指引

用户确认 v0.9 移动手感不错，但手会离开笔记本相机画面下沿或两侧。延续已授权的非 ML 调优，本轮 v0.9.1 补充取景反馈，保留已有控制算法与手势。

## 处理方式

当前识别使用镜像后的完整相机图像。预览虚线框是指针映射范围，不是相机裁剪框。扩大虚线框不能扩大视野；改变速度映射又会影响刚获得认可的手感。本轮只增加可关闭的提醒，并引导使用已有松中指换位操作。

独立监测器读取已经选中的控制手：观察拇、食、中、无名指指尖及四个掌指关节与图像四边的距离，忽略经常自然出画面的腕点和小指尖。接近边缘持续约0.12秒后提示，使用较宽的离开阈值和恢复等待减少闪烁。这只是关键点位置启发式，不能判断每个点是否真的可见，也不能保证在快速出画面前及时提醒。

桌面固定状态区显示取景提示；预览对应边缘画黄色条。启用系统控制期间，接近边缘或持续丢失控制手时显示可关闭的小型置顶提示，主窗口最小化时仍可见。提示不抢焦点、不接受鼠标和键盘输入；平台原生表现需真机验收。停止、相机停流、校准、演示或退出时隐藏。

普通移动提示松中指、将手移回画面中央、重新捏住；拖拽期间提示保持食拇捏合，只松中指换位。已经丢失跟踪时不判断一定出了画面，提示恢复控制手可见并重新接管。缺手松键、控制手身份锁定、重接管确认均保持现有逻辑；不在画面外预测轨迹或维持拖拽。

## 验证与范围

纯逻辑测试覆盖四边、角落、短暂异常、迟滞、丢失与恢复、非有限数据、腕点与小指排除。实际控制器的模拟输出回归确认提醒不改变指针和按钮序列，换位回到画面内不产生位移跳跃。离屏 UI 验证开关保存、停止隐藏、最小化提醒、焦点与输入标志，查看相关截图。
