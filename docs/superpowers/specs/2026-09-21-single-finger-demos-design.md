# 单指主动点击与停留点击 Demo

状态：2026-09-21，用户在单指候选设计之后明确要求两种方案均做 demo，并尽可能推进；主动点击优先。沿用已有授权直接实施。本轮保留捏合为默认主方案，两个单指候选只输出到应用内练习区。

## 操作与范围

只主动移动食指，其他手指可自然放松，但相机仍需看清足够的手部结构。食指相对掌部的位置控制指针，统一掌部尺度归一化；整体平移影响被抵消，旋转、透视和关键点噪声仍是局限。连续看见舒展食指后，以当前舒适手位对齐原指针；深弯、丢手、暂停后重新接管不跳回中心。增益提供三个档位。

- 主动点击：轻弯食指时先冻结指针，确认弯曲后等待恢复，完成一次弯曲—恢复才发出一对点击事件。过深弯曲、超时、丢手或换手取消，不留下按下状态。恢复后重设定位参照，避免指针回跳。弯曲灵敏度可调。
- 停留点击：接管后先移动；进入固定稳定范围后显示倒计时，离开则重新计时。每次仅点击一次，必须离开更大的重新准备范围才能再次点击。按未经裁剪的输入检查稳定，防止屏幕边缘持续移动触发。计时可调。
- 两种单指 demo 均只支持定位、左击和暂停，暂不支持拖拽、滚动或系统鼠标。训练采集仍使用原捏合标签格式，单指模式不能向该数据集录制。

## 模块与界面

新增纯逻辑 SingleFingerEngine、独立配置和特征提取，复用 HandFrame / EngineResult / InputEvent 接口。GestureEngine 和已有模型特征保持兼容。EngineResult 增加可选进度与提示，支持练习区的倒计时环和轻弯状态反馈。

界面提供捏合、单指轻弯、单指停留三个选项及相关参数，切换时停止当前任务、关闭系统输出并取消待触发动作。系统输出入口和分发层都检查单指限制。每次练习及离散事件记录模式和完整参数。合成回放分别演示两个候选，不能成为训练数据或真人效果证据。命令行可直接选择模式。

## 验证与交付

自动检查覆盖平移与缩放归一化、完整轻弯周期、噪声/超时/丢手取消、重接管、停留取消与重新准备、缓慢漂移和边缘裁剪、UI 模式隔离、训练数据隔离、配置与日志。用同一纯引擎驱动应用内八目标任务，证明工程链路连通；不据此报告真人准确率。两种模式均做离屏渲染及包内容检查，保留原捏合回归检查。
