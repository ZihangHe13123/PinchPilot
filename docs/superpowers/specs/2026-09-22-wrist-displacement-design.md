# 腕动位移实验模式

用户已授权继续非 ML 调优，并选定“转一点移动一段；停腕即停”的直接位移手感。目标是在前臂有支撑时工作，避免为保持手掌朝向而移动整条胳膊。本设计沿用已确认的捏合、点击、拖拽和换位动作。

## 选择

固定掌法向或腕到掌指关节的方向映射会漏掉某一旋转自由度，对自然握持姿势有要求。偏转控制速度不符合用户选择。因此采用掌部相对旋转，配合中立、向右、向上三个姿态示范，拟合两个用户指定的控制方向。

## 行为

- 新增独立“定位方式”：指尖位置（默认，旧行为）/手腕转动（实验）。保留三种滤波手感与连续灵敏度。
- 腕动首次使用需要12秒方向校准，每阶段3秒准备、1秒静止采样。依次保持自然握持、从中立轻向右转、回中立后轻向上转；拇中捏合，食指和无名指移开。
- 从腕与四个掌指关节形成掌部正交基，使用相对中立的旋转向量。两个示范方向的最小二乘系数映射到屏幕，默认每个示范幅度移动屏幕宽/高的四分之一。灵敏度仍连续可调。
- 不使用指尖位置来移动腕动光标。完整手部平移或统一缩放不改变理想几何下的朝向输出。停止旋转后滤波收敛，不因维持偏转持续移动。
- 松中指锁住光标；回到舒适姿势再捏住，重新锚定，光标不跳。点击与拖拽的冻结、松键、再接管继续使用同一状态机。
- 腕动模式将捏合距离与掌尺度统一在同一估计3D坐标系。位置模式保持原算法。此调整只消除尺度定义不一致，不能修复模型错误的深度、遮挡或缺手。
- 缺少有效校准、退化掌形、过大朝向跳变或超出已校准中立姿态的角域时暂停并释放按键；重新接管仍需食指移开。提示区别无校准、姿态不可用、跟踪跳变。不会在缺手时盲目维持拖拽。
- 校准失败/取消不覆盖此前有效结果；开始、切换模式、关相机、超时和退出停止输入。成功不自动启用鼠标。
- 保存15个校准参数和定位方式，不保存采样帧。原位置静止噪声校准仍保留，但腕动暂不应用，防止坐标单位混用。

## 边界

使用当前MediaPipe关键点的估计深度，无新模型训练。三个姿态使用相同手和机位；示范旋转幅度8–35度、方向分离至少30度；每阶段样本连续且稳定。超过相对中立65度的姿态不用于控制，避免远离校准的小角域。改变机位、惯用手或握持姿势后需重做校准。

## 验证

合成刚体旋转验证方向、增益、平移/尺度不变性；退化/近共线/过小/过大/不稳定校准拒绝；有噪声静止、正反向、停止、捏合点击扰动与松中指重锚；缺手/换手/超时/角度跳变期间按键恰好释放一次。用FakeMouse验证模式切换和校准停止，离屏Qt检查偏好恢复及界面流程。保留位置模式的现有轨迹基线。

合成结果不能证明真人疲劳、真实追踪精度、遮挡鲁棒性或Mac/Windows实际手感。交付标为可试用实验，真人先预览再启用鼠标，与现有位置模式直接比较。
