# PinchPilot：双平台摄像头捏合交互原型

状态：依据本次会话已批准的方案实施。用户授权尽可能推进，并明确要求 macOS 和 Windows。

## 目标与边界

普通 RGB 摄像头提供 21 个手部关键点，以小幅手部移动定位，拇指与食指捏合点击、持续捏合移动拖拽，明确的 V 手势用于滚动。单手、单主屏是首版验收范围。默认仅在应用内预览；真实鼠标控制必须由用户在界面启用。演示回放永不输出系统鼠标事件。

首版交付工程闭环、数据采集、个人阈值校准、可替换规则/ML 识别器、分组训练和评测、目标点击练习。真实跨用户性能与舒适度需要参与者数据，不以合成测试充当结果。

## 技术栈与模块

- Python 3.11、uv、PySide6 桌面界面，核心数学逻辑不依赖 GUI。
- OpenCV 摄像头读取，MediaPipe Tasks Hand Landmarker 在工作线程中处理，单个最新结果槽避免界面积压；原始视频默认不落盘。
- NumPy 特征、scikit-learn RandomForest/SVM、JSONL 数据、joblib 本地产物、matplotlib 评测图。
- 独立鼠标适配层：macOS Quartz，Windows ctypes/Win32；只有显式启用后构造真实输出。主屏坐标和 DPI 按平台处理。紧急停止、跟踪超时、异常及关闭均释放按键。
- 数据层：每条记录有 participant、session、episode、人工标签、单调时间戳、原始归一化关键点和图像宽高比。handedness 置信分数不冒充关键点置信度。

## 交互与可测贡献

规则基线用按手掌尺寸归一化的捏合距离，具有闭合/释放滞回和按时间确认。稳定定位使用手掌参考与速度自适应低通滤波。捏合确认时锁定按下位置，超过明确位移才拖动；提供稳定定位开关，便于比较。停止/丢手优先结束输出，恢复后必须看到张开手才允许再次按下。

ML 首先学习 pinch/open/scroll/other 的可观察手形，采用与训练一致的几何特征；界面允许加载本项目训练的本地模型。预测分数可拒绝不确定输入，事件生命周期始终由确定性状态机管理。只有有真实数据和基线证据时再实现时序网络，不把额外网络当作已交付能力。

个人校准分别录张开与捏合距离，检查两者分离度，用稳健分位数生成阈值；失败不覆盖原配置。校准过程禁止真实控制。分组实验要求先划分人员或独立场次再训练；没有足够分组直接拒绝生成可信评测结论。

## 验收

1. 两个平台安装入口、固定依赖、无摄像头演示可启动。
2. 核心回放覆盖捏合一次触发、拖拽、滚动互斥、丢手/停止释放、重新张开后恢复、未知输入不按下。
3. 录制标签由用户提供，规则预测不作为监督真值；文件可被检查和训练命令消费。
4. 训练报告包含数据来源、分组、样本量、规则/模型对照、混淆矩阵及适用边界。
5. Mac 上实际验证依赖、模型初始化、界面、回放和合成流程；Windows 增加 CI 配置和安装脚本，实机验证单独标记。
6. 不安装或运行参考产品，不发送外部消息，不修改参考仓库，不提交 Canvas。

## 来源与独立贡献

交互概念参考 Meta 的 pointer/pinch 交互；系统职责划分参考 Pawvis，但本项目独立实现。Pawvis 已有 DTW 自定义模板、校准和稳位，不将这些描述为本项目首创。研究问题是当前设计在普通摄像头、小幅动作下的效果，需与可靠规则基线及实际产品实验比较。
