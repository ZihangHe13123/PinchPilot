# 右键与拖拽体验版

日期：2026-09-21。用户认可 v0.5，要求补充常用右键、拖拽，先体验，满意后再做数日试用版本。用户已选择拇指＋无名指轻捏直接右键。本轮在原有推进授权下完成应用内体验版 v0.6；日常系统控制版待用户体验反馈后再启用。

## 操作与取舍

- 定位仍用拇中捏合中点；沿用 v0.5 的映射、滤波、死区和接管确认。松中指锁住位置，重新捏合从原位置继续。
- 左键改成食拇确认接触时 `down`，分开确认时 `up`。短捏是一次单击，取消 v0.5 的接触瞬间 `down/up`，这样拖拽之前不会先多出一次单击。按下立即有颜色反馈，完整单击在松开时完成。
- 持续食拇捏合约 0.30 秒进入拖拽就绪，进度环提示等待。就绪时重设参照，之后保持捏合、移动拇中点拖动，松食指放下。等待期间冻结，避免接触挤压造成拖动。没有额外捏一次锁定的隐藏模式。
- 拖拽时松中指只冻结位置，食拇仍捏着就保持左键；重新捏住中指约 0.12 秒后可继续拖。食拇分开始终结束按住。这样可在小范围内换位。
- 右键使用食指在外侧时的拇无名指接近；先冻结，再确认接触，发出一次右键 `down/up`，保持不重复。无名指须先被观察到离开，启动时一直蜷着不会触发右键。支持中指保持捏合和松开锁定位两种情形。
- 食拇操作进行中不触发右键；两种点击同时接近时，取消未确认动作并要求分开，不猜测意图。右键完成后须松开无名指，才恢复定位或接受下一次点击。

曾考虑把食拇长按用于右键，或通过菜单选择拖拽；前者与拖拽冲突，后者多一步选择。本轮选择独立无名指右键、标准左键按住拖动，实际费力度和误触仍需体验。

## 状态与中断

定位 `CONTROL`、锁定 `FROZEN` 保留。左键接近 `APPROACH` → `PRESSED` → `DRAG` → 食拇分开 `CONTROL/FROZEN`。右键 `RIGHT_APPROACH` → `RIGHT_TOUCHED` → 无名指分开。切换不明确时 `WAIT_CLEAR`，无按键按住。

丢手、过期帧、非递增时间、换手、跳变、Esc、停止、参数或模式切换均结束按住。引擎重置必须返回释放事件；处理返回帧时不能吞掉超时释放。取消的按住不计成练习任务成功；重新接管仍要求食指离开。新右键与拖拽状态不计入静止定位统计。

## 界面、事件与验证

- 应用内任务增加右键目标，开放三指拖拽；按错误按钮不得算成功。保留物理鼠标对照，并记录实际/期望按钮和任务类型。
- 预览显示食拇、拇无名指连接及距离；右键使用独立颜色，拖拽按住/进度反馈明确。保留移动和左键触碰设置，提供拖拽等待与右键触碰档位。
- 事件增加 `right_down/right_up`，准备 Mac/Windows 适配与模拟接口验证，但三指到系统输入的双层禁止保持生效。训练集仍隔离，不训练新模型。
- 单元检查覆盖右键确认/只触发一次/初始蜷指/互斥，左键按下到释放、等待不位移、拖拽、锁定换位、中断释放与异常返回帧。GUI 检查错误按钮、取消不记成功、任务切换及设置生命周期。
- 通过真实引擎处理合成输入，各跑保持中指左击、松中指左击、右击、拖拽八目标；核对固定噪声下普通定位输出不变，查看截图，打包并验证 wheel 启动。
