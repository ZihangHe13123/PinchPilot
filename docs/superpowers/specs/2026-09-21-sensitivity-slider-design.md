# 移动灵敏度滑条

用户反馈 v0.7 最慢的 40% 定位范围有时仍快，明确要求改用滑动控制。随后提出补充滚轮，两项合并为 v0.8.0；保留现有三指手势和滤波，桌面工具与研究界面共用一个滑条。

采用直接速度倍率 0.10×–2.00×，步进 0.01×，向左变慢；1.00× 对应既有默认 span=0.30，旧慢档 span=0.40 对应 0.75×。延续 span=0.30/gain 的现有移动映射，配置允许的 span 上限扩展到 3.0。低速下需要更大移动或松中指换位，这属于速度的明确取舍。

与继续增加离散档位相比，滑条支持细调；与直接显示反向百分比相比，速度倍率更容易理解。保留现有“手感设置”位置，附当前倍率和恢复 1.00× 按钮。

拖动中只预览数值，松手再应用，避免第一步变化就松开系统按钮、打断滑条拖动。键盘调整按步进立即应用。应用参数沿用已有停止控制/松键流程，不自动重新启用。

桌面设置仍保存 span，兼容已保存的 20%/30%/40% 配置；恢复时只接受有限且在范围内的数值。当前用户的 span=0.40、强抗抖等设置不主动改写。

验证滑条映射与延迟应用、旧设置迁移和新值往返保存、同样手位移在低倍率下的指针位移、参数改变时松键；检查 GUI、默认噪声轨迹、包内容与新入口。当前已运行的旧窗口需正常重启后才加载新代码，不在运行期间修改其内存状态。
