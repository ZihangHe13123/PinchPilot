# 拇中捏合定位，食指触碰点击

2026-09-21：用户报告 v0.3 单指定位严重晃动、难以使用，要求暂时搁置。随后给出具体替代操作：拇指和中指捏住开始控制，用其接触位置定位，食指碰入算一次点击。沿用此前推进原型的授权实施这个候选；不再优化单指方案，也不把其合成测试成功当作真人可用证据。

## 操作约定

- 拇指与中指尖连续靠近约 0.1 秒，且食指在外侧，进入定位；以两指尖的二维中点估计接触点。普通相机不直接检测皮肤碰撞，靠近判定是归一化三维关键点距离代理。
- 移动捏合点控制指针。松开拇中或丢手立即停止；再次捏住从原指针位置继续，不跳回中心。默认相机宽高各 30% 的活动范围，可调 20%/40%。定位坐标不逐帧除以掌部尺度，避免尺度变化放大位移。
- 食指接近两指时，先冻结当前指针；连续进入接触阈值后立即产生一对点击事件，无需等食指抬起。保持触碰只点一次；食指离开较大的释放阈值后才重新准备，同时重置位置参照避免回跳。
- 启动时三指已靠在一起不点击，先移开食指。丢手、换手、关键点大幅跳变、非递增时间戳均取消待确认动作，重新接管必须再次观察到食指离开。

本轮先做应用内定位、点击、暂停；不加入保持触碰拖拽或滚动，避免首轮同时改变过多语义。原捏合完整模式保留，旧单指入口标记“暂搁置”。新模式有独立的 Mac/Windows 启动脚本，不自动打开摄像头或接管系统输入。

## 稳定定位

采用两指中点、三帧中值、随速度调整的低通，以及连续的径向死区。死区内保持原位，超出后只跟随超出的位移，避免硬阈值一越界就跳动。默认死区为归一化屏幕坐标 0.008，可选较轻/默认/较强；代价是精细小移动可能被抑制，因此不宣称越强越好。接触前冻结与普通定位抗抖分别测试。

两个定位指尖也会因遮挡、食指触碰的机械联动或模型估计而变化。本轮针对这些问题提供拒绝异常、时间确认与冻结，但不能保证消除。只把合成噪声实验解释为指定输入下的工程结果。

## 模块、诊断与记录

新增独立 TripodEngine 和 StablePointer，复用帧/事件接口；新模式不进入原捏合四分类训练集。GUI 显示拇中距离、食指接触距离与交互状态，提供范围、抗抖强度和接触灵敏度。

增加用户手动开始的 8 秒静止记录：提示捏住拇中、食指移开、保持舒适静止；记录新相机帧上的原始映射点和处理后点、状态及配置。不保存视频，不自动开始采集。报告有效定位时长/覆盖与两条轨迹的离散程度；冻结点击、暂停及丢手不被当作零抖动定位样本，样本不足明确标记，不能当作准确率或真实运动真值。

## 验证与交付

覆盖接管和释放、接触即时单击、保持不连点、离开后再触发、提前冻结、松开后不回跳、缺失/时间间隔/换手/大跳变取消、3D 距离与平移缩放、固定映射不受尺度噪声影响、死区内静止与持续慢移、孤立异常点、合成噪声与响应取舍。GUI 检查模式隔离、禁止原生输出与标签混用、参数日志；合成八目标贯通及离屏渲染。

最终交付源码、启动入口、使用说明、自动检查和诊断工具。需要用户用真实相机验证的仍是三指靠近遮挡、舒适支撑姿势与点击准确度，以及 Windows 硬件。本轮不训练 CNN、不自动控制相机或系统鼠标。
