# 0.12 诊断与交互测试

本版让“刚才为什么不好用”留下可分析的证据。兼容定位与手势继续使用 0.11 的算法和参数。新的工具不需要先提供真人数据；也不把合成验证算作真人改善。

## 启动

先退出旧窗口，Mac 双击项目根目录 `launch_desktop_mac.command`；Windows 用 `launch_desktop_windows.cmd`。当前源码标题应为 **0.15.0**，本页的诊断与测试功能从0.12开始提供。已留档的0.11 ZIP保持原样，未包含这些工具。

启动时相机和系统输入均关闭。新按钮位于右侧可滚动的设置区，「打开测试记录」下面。

## 先做一次短测

1. 启动相机预览，保留日常使用的灵敏度与兼容定位。
2. 点「打开交互测试台」。系统鼠标控制会先关闭，手势只移动测试台里的虚拟光标；实体鼠标可操作窗口按钮。
3. 选任务并点「开始本项」。先松开食指，再拇中捏合移动，按照任务提示操作。
4. 完成、取消或关闭会保存结果至 `reports/practice/`。换画面来源或修改控制参数会结束当前任务，避免混用条件。
5. 关闭测试台后，需要手动「启用鼠标控制」才能继续操控桌面。Esc 可关闭测试台并停止控制。

| 任务 | 判定 | 记录含义 |
|---|---|---|
| 小目标点击 | 按下与松开均在目标圆内 | 完成目标、配对按钮尝试、未命中、耗时 |
| 连续双击 | 同一目标两次有效松开相隔不超过0.50秒 | 固定任务协议，不是操作系统双击设置或应用是否接收 |
| 拖拽放下 | 从方块按下，进入拖拽状态，再到圆内松开 | 到位且正确释放才完成；中断不冒充成功 |
| 反向微调 | 远移后点相邻反向小目标 | 观察最后几像素与反向启动，不据此自动推断疲劳 |
| 滚动后停住 | 保持V，将滚动值送到绿色区并无滚动事件保持0.70秒 | 台内滚动数值，不是网页真实滚动距离 |

所有距离均为测试画布逻辑像素，画布尺寸和控制参数写入报告。每轮从“开始”计时，包括重新捏合和纠错。重复比较时保持窗口尺寸、任务、灵敏度、机位和姿势一致。本版没有实体鼠标对照评分；实体鼠标只操作窗口。

「查看合成演示」也能驱动测试台，但来源明确标记 `synthetic_demo`；不会自动完成固定目标，不能拿它作为你的成绩。

## 标记刚才的问题

选“抖动 / 迟滞 / 点击没响应 / 误点击 / 丢手断触 / 其他”，再点「标记刚才的问题」，或本应用在前台时按 F8。保存最近最多约10秒的原因、状态、阈值余量和软件耗时摘要。

正常日志开启时，标记写入 `reports/desktop_trials/trial_*.jsonl` 的 `issue_marker` 行并立即刷新到磁盘。关闭正常日志时，**这次明确的标记动作**单独写入 `issue_*.json`，不会重新启用日志。不保存相机图片、视频、手部关键点或桌面光标轨迹；记录仅在本机，不自动上传。它是用户报告的问题，不是自动生成的真值标签或误触率。

原因包括点击前冻结、松中指锁定、捏合暂不稳定、正在确认控制手、只有另一只手等。左右手分类分数不是关节可见度；已经重置且无法追溯的历史原因不会猜测。阈值余量正值只表示满足该数值门槛，其他时间/状态条件仍然适用。

## 查看卡顿发生在哪一段

「查看诊断与分段耗时」展示最近样本、P95、样本数：相机read、图像预处理、推理、等待界面接收、手势/移动计算、本地鼠标发送、界面轮询间隔。每阶段保留最近最多180个有效样本，切换来源重置样本。未测到的阶段显示“—”，例如未启用系统输入时没有鼠标发送样本。

`read`包括等摄像头返回的时间；读帧后帧龄从read返回开始，既不包含曝光/驱动队列的真实帧龄，也不证明系统和显示器已响应。分段P95不能相加当端到端延迟。「最新结果槽覆盖」指GUI取走结果前被较新推理结果替换，符合现有只处理最新结果的策略，不等于摄像头丢帧。

## 不用相机的可重复对比

项目目录执行：

```sh
uv run pinchpilot compare-tripod --output reports/replay-comparison.json
# 有需要才保存逐帧虚拟指针/事件：
uv run pinchpilot compare-tripod --output reports/replay-trace.json --trace
# 使用既有录制格式（不会自动录制新的关键点）：
uv run pinchpilot compare-tripod --recording data/recordings/你的文件.jsonl --output reports/recorded-comparison.json
```

固定seed20260922生成静止抖动、平移、边缘反向、点击/拖拽、缺手/时间间隔五组输入，同帧同初始指针运行兼容定位、位置精细、位置经典。命令行使用1920×1080逻辑坐标、span=0.30，报告包含完整配置、输入哈希、生成事件、轨迹长度和中断情况；抖动只在明确标记的合成静止区间、所有方案均处于移动接管的共同帧上统计。真实录制没有静止标签就不计算“静止精度”。

回放使用当前引擎的三套配置，不是运行旧版二进制；不会打开相机或发送系统鼠标事件，不加载训练模型。`--trace`会明确额外保存输入捏合点与虚拟指针坐标，这和默认日常诊断日志的摘要范围不同。

## 下一步拿这些记录做什么

先找重复出现的原因与耗时瓶颈，再改一个具体参数或模块。使用同帧回放防止点击/释放/换位等退步，用固定任务比较试用前后。学习模型需要额外的真实动作及人工标注；本轮没有训练模型，也没有凭日志声称准确率、疲劳或跨用户泛化提升。
